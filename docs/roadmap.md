# 进度与后续

## 0.1 已完成（地基）

**应用骨架**
- MyGo 原生窗口，无 WebView；隐藏标题栏、自绘窗口按钮
- 标题栏：侧栏开关、快速跳转、命令面板（Ctrl+Shift+P）、文件 / 编辑 / 视图 / 帮助菜单
- 侧栏：软件名、动作（新建 / 搜索 / 打开知识库 / 发现）、文档树与大纲切换、最近打开、工作区间
- 卡片式文稿区：标签栏、正文、状态栏（保存状态 / 编码 / 行数 / 显示方式）
- 目录树与标签的右键菜单；中键关闭标签；标签溢出时的左右滚动箭头
- 快捷键：`Ctrl+K` 快速跳转、`Ctrl+N` 新建、`Ctrl+S` 保存、`Ctrl+W` 关闭、
  `Ctrl+O` 换知识库、`Ctrl+,` 设置、`Ctrl+Shift+R` 重新扫描
- 800ms 自动保存，原子写入；重启恢复上次打开的标签
- 设置：主题、字号、阅读宽度、知识库位置、同步、插件启停

**Markdown**
- 分栏 / 预览 / 源码三种模式；源码用 `ui/editor`（语法高亮、多光标、查找、折叠）
- 预览用 `ui/markdown`：GFM 表格、任务列表、删除线、脚注、公式
- 图片按文档相对路径加载；站内链接直接跳转；任务框可点并写回原文

**查看器**
- 图片：PNG/JPEG/GIF/WebP/BMP/SVG，适应窗口 / 1:1 / 缩放
- PDF：整页交给 folio 渲染（见 0.1.9），连续滚动、文字选择、查找、缩略图、批注
- Word：`.docx` → Markdown（标题、粗斜体、列表、表格）
- 纯文本：按扩展名高亮
- 白板：`.excalidraw` 原生绘制，可新建矩形/椭圆/菱形/箭头/直线/文字、拖动、删除、保存
  （内置功能，`Ctrl+Shift+P` › 新建白板）

**插件**
- 清单校验、zip 安装（路径与摘要校验、原子替换）、卸载、启停
- `Host` 契约（命令 / 面板 / 编辑 / 提示）
- 插件只做第三方扩展：所有第一方能力都编译进本体，不绕一层插件

**同步**
- 文件级三方同步：上传 / 下载 / 删除传播 / 冲突保留两份 / 删除刹车
- 远端：文件夹、Git、WebDAV 网盘、库自己的 git 仓库（自建 HTTP 服务在 0.2 期间移除，留待以后再做）
- 首次接上一个已有文件的远端：本地版本整批收进 `.papero/join-<时间>/`，不在文稿树里散冲突副本
- WebDAV 写入带 `If-Match` 条件写，ETag 对不上就拒绝，而不是盖掉另一台设备的改动
- 从云端拉取（只下载，不传不删）+ 打开时自动拉一遍；限速时整轮停下但保留进度

**工程**
- 40+ 个单元与集成测试，含无窗口界面测试（`ui.NewTester`）与真实 PDF 冒烟测试
- `go run . -shot out.png` 无窗口渲染，用于检查外观

## 已知限制

- Markdown 编辑是「源码 + 预览」，不是所见即所得；
- PDF 由 folio 渲染，页面外观与原版一致；但只引用标准 CJK 字体、自己不嵌字体的老 PDF
  会出乱码（缺 Adobe CMap），加密 PDF 明确报错；
- `.doc`（旧二进制格式）、`.pptx`、`.xlsx` 暂不支持；
- 白板只支持 Excalidraw 的常用元素，不渲染手绘笔触的粗糙风格（roughness）；
- 同步是手动触发，冲突不做块级合并。
